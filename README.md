# Rackitect

**A visual rack planner for home labs, network closets, and small infrastructure setups.**

Rackitect helps you sketch, organize, and document rack layouts directly in the browser. Drag devices into a rack, adjust rack size, track ports and power, and export your layout when you want to keep a copy or move it somewhere else.

## Live Demo

[Open Rackitect](https://lucacri.github.io/Rackitect/)

## Features

- **Visual rack layout** — drag devices into rack units and rearrange them quickly.
- **Flexible rack sizes** — switch between common rack heights from compact home-lab racks to full cabinets.
- **Built-in device library** — includes common networking, compute, storage, power, KVM, UniFi, and shelf items.
- **Custom devices** — create or edit device templates with size, category, ports, and power details.
- **Shelf support** — place smaller devices like mini PCs, Raspberry Pis, ONTs, and bridges on rack shelves.
- **Power overview** — track rack power capacity and estimated device draw.
- **Port metadata** — document RJ45, SFP, USB, HDMI, serial, IPMI, and other connections.
- **Local persistence** — layouts are saved in your browser automatically.
- **Import/export** — save layouts as JSON and load them again later.
