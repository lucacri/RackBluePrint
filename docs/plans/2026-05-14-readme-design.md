# README Design: Rackitect

## Goal

Create a polished GitHub README for Rackitect, a personal React/Vite app for visually planning server and network rack layouts.

## Structure

- Use **Rackitect** as the project title and primary brand.
- Include a concise tagline and overview for home lab and small infrastructure users.
- Highlight core features: drag-and-drop rack layout, selectable rack sizes, built-in and custom devices, shelves for small gear, power/port metadata, local persistence, and JSON import/export.
- Include a live demo link for GitHub Pages at `https://lucacri.github.io/Rackitect/`.
- Add a screenshots section with a placeholder for future images.
- Keep the README neat and public-facing for a personal GitHub account.
- Move local run instructions into a separate lightweight file, linked from the README.

## Supporting File

Create a dedicated quick-start file for local development, likely `DEVELOPMENT.md`, with only the essential commands to clone, install dependencies, run the dev server, build, and preview.
